# 국내 주식 반전매매(평균회귀) 퀀트 시스템

가격과 이동평균의 괴리(spread)가 평균회귀 과정을 따른다는 가설을
확률미분방정식(오른스타인-울렌벡 과정) 수준에서 먼저 검증하고, z-score 신호로
표준화한 뒤 30종목·3,900건 규모로 재검증해 증권사 API 자동매매까지 구현한
개인 퀀트 프로젝트입니다.

## 진행 순서 (실제 방법론이 뒤집힌 과정 그대로)

| 파일 | 단계 | 내용 |
|---|---|---|
| `01_sde_theory_verification.py` | 이론 검증 | spread를 OU 과정으로 가정하고 1차 자기상관·분산비로 평균회귀 후보 스크리닝 |
| `02_kalman_ou_calibration.py` | 파라미터 추정 | AR(1) 회귀 + 칼만 필터로 theta(회귀속도)·mu·sigma 추정 |
| `04_sanity_check_random_walk.py` | **재검토** | 몬테카를로로 순수 랜덤워크와 비교 — 표본이 작을 때 가짜 신호 발견 → 방법론 재설계 |
| `05_threshold_scan.py` | 재설계 | z-score 임계값을 데이터 기반으로 스캔, event study t-검정으로 유의성 확인 |
| `06_portfolio_diversification.py` | 재검증 | 30종목 · 국면별 3,900건으로 표본 확장, 포트폴리오 수준 t=2.44로 재검증 |
| `09_auto_trading_architecture.py` | 실전 구현 | 4단계 리스크 관리 규칙(손절 -10% · 시간제한청산 · 서킷브레이커 · 일일손실한도 -25%)과 함께 증권사 API 연동 자동매매 아키텍처 구현 |

## 핵심 발견

- 처음 세운 가설(spread 자기상관만으로 평균회귀 판단)은 표본이 작을 때
  랜덤워크와 구분이 잘 안 된다는 걸 `04_sanity_check_random_walk.py`에서
  몬테카를로로 확인 → **z-score 임계값을 데이터 기반으로 다시 탐색**하는
  방향으로 방법론을 바꿈
- 단일 종목 결과가 우연인지 확인하기 위해 30종목·3,900건으로 표본을 넓혀
  재검증 → 포트폴리오 수준에서 t=2.44로 통계적 유의성 확인
- 검증된 신호도 리스크 규칙 없이 그대로 자동매매에 넣지 않고, 4단계
  리스크 관리 규칙을 신호 로직과 분리해서 구현 (신호가 나와도 규칙에 걸리면 무효화)

## 실행

```bash
pip install -r requirements.txt
python src/04_sanity_check_random_walk.py
python src/06_portfolio_diversification.py
```

각 스크립트는 `__main__` 블록에 더미 시계열 예시가 포함되어 있어 바로 실행해
볼 수 있습니다. 실제 종목 데이터로 쓰려면 `price_by_symbol`에 OHLCV 종가
시계열을 넣으면 됩니다.
