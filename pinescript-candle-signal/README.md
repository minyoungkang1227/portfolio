# Pine Script 캔들 신호 · 변동성 지표

공개 지표를 분석해 진입 신호로 결합한 프로젝트입니다. 캔들 구조(몸통/꼬리 비율)와
거래량 델타를 결합한 변동성 지표에 추세 필터를 더해 하나의 진입 시그널로 만들고,
TradingView 차트에서 백테스트로 민감도와 룩백 기간을 조정했습니다.

## my_filter/ — 직접 설계한 부분

`candle_volume_entry_filter.pine`이 실제로 제가 설계·구현한 코드입니다.

1. **캔들 구조 스코어**: 몸통이 전체 고가-저가 범위에서 차지하는 비율(body %)과
   진행 방향 반대쪽 꼬리 비율로 캔들의 "형태적 신뢰도"를 0~1 스코어로 계산
2. **거래량 델타 스코어**: 평균 거래량 대비 스파이크 배율을 0~1로 정규화
3. **추세 필터**: 이동평균(EMA/SMA/WMA 선택 가능) 대비 방향이 일치하는 캔들만 통과
4. **결합**: 구조·거래량 스코어를 가중합한 뒤 추세 정렬 여부를 곱셈 마스크로 적용,
   개인 퀀트 프로젝트(반전매매 시스템)에서 썼던 것과 같은 방식으로 0.50~0.75 구간을
   스캔해 승률·손익비가 가장 안정적인 임계값(0.62)을 채택

원본 지표들은 각각 거래량 스파이크 탐지 / 캔들 내부 델타 / RSI 추세만 따로
제공했는데, 이걸 하나의 연속 스코어로 합치고 추세 필터를 곱셈 마스크로 적용한
결합 로직이 이 프로젝트에서 새로 설계한 부분입니다.
