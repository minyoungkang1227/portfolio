## 프로젝트

- **[quant-reversal-system](./quant-reversal-system)** — 국내 주식 반전매매(평균회귀)
  퀀트 시스템. OU 과정 이론 검증 → 랜덤워크 재검토 → z-score 임계값 재설계 →
  30종목·3,900건 재검증(t=2.44) → 4단계 리스크 관리 자동매매 구현
- **[db-insurance-risk-modeling](./db-insurance-risk-modeling)** — 제16회
  DB보험금융공모전 "AI 리스크 보험 상품 모델링". 복합포아송·로그정규 결합분포,
  몬테카를로 시뮬레이션, VaR 95%/99% 산출 및 민감도 분석
- **[pinescript-candle-signal](./pinescript-candle-signal)** — 공개 캔들/거래량
  지표를 분석해 직접 설계한 결합 진입 필터(body/wick 비율 + 거래량 델타 +
  추세필터), 원본 지표는 라이선스와 함께 별도 표기
